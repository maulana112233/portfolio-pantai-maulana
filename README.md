# 🏖️ Website Portofolio Pesisir Pantai & Neo-Brutalisme
### Maulana Ichsan — Siswa Kelas X TKJ 1 SMK Telkom Malang

Portofolio interaktif modern bertema pesisir pantai (*coastal neo-brutalism*) berbasis **React 19 + TypeScript + Vite + Tailwind CSS**. Dilengkapi simulasi ombak murni HTML5 2D Canvas, fisika gerak karakter interaktif, **huruf nama interaktif yang bisa digeser dengan kursor**, mini game arcade **Packet Surfer**, **showcase 4 sertifikat resmi dengan zoom modal**, **animasi scroll interaktif di seluruh halaman**, pipeline penguasaan *tech stack*, linimasa pendidikan dinamis, serta dock kontak bento.
